# Заметки к релизу

Текст «What's new»: карточка обновления в приложении, GitHub-релиз и анонс в Telegram. Как CI их
собирает — `docs/updates.md`, раздел 13 → «Заметки к релизу».

- `beta.txt` — английский, **перезаписывается** в каждом пуше в основную ветку, который соберёт beta
  (затронуты `app/` / `core/`): что меняется для пользователя с прошлого пуша. Не дописывать к старому —
  CI сам собирает все версии файла с прошлой beta. Не менялся — в заметки идут темы коммитов.
- `X.Y.Z.en.txt`, `X.Y.Z.ru.txt` — к stable `X.Y.Z`: кратко обо всём, что изменилось с прошлого stable
  (источник — история `beta.txt` и коммиты с прошлого тега: `git log vA.B.C..HEAD -- release-notes/beta.txt`).
  Пишутся в тот же проход, что русский перевод интерфейса (`docs/i18n.md`); без них stable не выйдет.

Формат: простой текст, без Markdown (приложение показывает как есть); пункты — строки с `• `;
для пользователя, а не про внутренности; анонс в Telegram ≤ 4096 символов (длиннее — обрежется с «…»).

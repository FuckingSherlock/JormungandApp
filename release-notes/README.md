# Заметки к релизу

Текст «What's new»: карточка обновления в приложении, GitHub-релиз и анонс в Telegram. Как CI их
собирает — `docs/updates.md`, раздел 13 → «Заметки к релизу».

- `beta.txt` — **по-русски**, саммари беты: тот же текст, которым ведущий сообщает пользователю, что
  вошло в сборку. **Перезаписывается** в каждом пуше в основную ветку, который соберёт beta (затронуты
  `app/` / `core/`): что меняется с прошлого пуша. Не дописывать к старому — CI сам собирает все версии
  файла с прошлой beta. Не обновлён — beta не выпустится (запушить саммари — сборка перезапустится).
- `X.Y.Z.ru.txt` — к stable `X.Y.Z`: кратко обо всём, что изменилось с прошлого stable (источник —
  история саммари: `git log -p vA.B.C..HEAD -- release-notes/beta.txt`). Пишется в тот же проход, что
  русский перевод интерфейса (`docs/i18n.md`); без него stable не выйдет. `X.Y.Z.en.txt` пока не пишем
  (тестируют русскоязычные); CI его понимает, если появится.

Формат: простой текст, без Markdown (приложение показывает как есть); пункты — строки с `• `;
для пользователя, а не про внутренности; анонс в Telegram ≤ 4096 символов (длиннее — обрежется с «…»).

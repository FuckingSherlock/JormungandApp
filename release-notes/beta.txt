• DNS: состояние серверов (работает / не работает) теперь запоминается и переживает переподключение и перезапуск. При подключении сразу берётся сервер, который работал в прошлый раз; неработающие проверяются заново сразу, а не считаются живыми. Неработающий сервер распознаётся примерно за 15 с вместо 30.
• DNS: при смене сети или ноды активный сервер сразу перепроверяется. Пока идёт перепроверка, в листе DNS у сервера крутится индикатор, прежнее состояние остаётся видно.
• DNS: исправлено — запросы уходили на выключенный DNS-сервер (служебные загрузки, например подписки).
• Правила с «Если недоступна → Direct»: пока правило работает напрямую, его адреса резолвятся через рабочий DNS, а не через первый в списке.
• Адреса серверов нод определяются системно: через включённые встроенные DNS (рабочие первыми), системный DNS — последним, при неудаче — через выключенные. Ваши DNS-правила на это не влияют. Если адрес сервера ноды не существует (ошибка в подписке), после повторной проверки появляется событие об этой ноде; уведомление — только если нода сейчас используется.
• Внешний IP и страна: запоминаются для каждой ноды и показываются сразу; проверка идёт в фоне не чаще раза в час на ноду (после обновления подписки — сразу), пока идёт проверка (в том числе после смены ноды), под флагом крутится индикатор, а если проверка не удалась — вместо IP показывается ошибка. Ручная проверка — в любой момент, она сдвигает таймер. Прямой IP без VPN проверяется заново только при смене сети.
• Проверка сайтов: при сбое сайт проверяется сначала через ту же ноду, затем через рабочую ноду той же подписки в другой стране и внешним сервисом, затем через ноды других подписок. Повторы сбоев не теряются: собираются в одно событие со счётчиком.
• Неработающие ноды перепроверяются по лестнице 1–2–4–8–15–20 мин, она сохраняется при переподключении.
• Подписки: пустой ответ или ошибка одной из сторон загрузки больше не даёт ложного события; расхождение копий — только если различаются сами ноды.
• Сохранение файлов (лог, бэкап): приложение запоминает папку. «Сохранить» — сразу туда с подтверждением, «Выбрать папку» — сменить её.

# Миграция на sing-box-lx — план на 3 исполнителей (я + 2 агента), 2026-11-14

**Scope: только Android.** Windows-версия приложения не нужна: никакой релизной поставки
Windows-бинаря; `sing-box.exe` из lx собирается только как локальный инструмент тестов
(`core/tool/bin/`, через него `dart test` гоняет `sing-box check`).

Ядро: `Leadaxe/sing-box-lx`, база апстрим 1.14.4. Имена `sing-box.exe` / `libbox.aar` НЕ меняются —
обновления, killjob, docs/updates.md остаются как есть.

## Решения (приняты, не пересматривать)

- **Пин**: тег `v1.14.4-lx.33` (при старте перепроверить — мог выйти новее lx-релиз на базе 1.14.4).
- **Тег-сет**: апстримовский (читается из чекаута) + `with_xhttp`. `with_lx_command` НЕ включаем.
- **Сборка из исходников** (клон тега → аудит → сборка); их CI-артефакты не используем.
- Reality `key_share` — дефолт lx `hybrid`, конфиг-генерацию не трогаем.
- `splithttp` остаётся unsupported (только `xhttp`).
- Kill switch к миграции отношения не имеет: реализовано только удержание системного прокси на
  десктопе (`service.dart`, `sysproxy.dart`; полный блок WFP/TUN не сделан; на Android выключен,
  `platform_caps.dart:24 killSwitch => !android`).
- Ветка миграции — с текущей (`claude/karing-fork-environment-a45c2c`); коммиты — по слову пользователя.

### Агент 2 — coder «Сборка (B) → Фичи (C)» (два пакета подряд)

**Пакет B — сборка и CI** (сразу, параллельно с аудитом):
1. `core/tool/build_libbox.ps1`: `-Repo`/`-Tag` (дефолт — прежний апстрим-режим), `with_xhttp` в тегах;

2. Собрать `libbox.aar` из lx → apply_android_overlay; собрать локальный тестовый `sing-box.exe` из lx

3. `.github/workflows/release-android.yml`: `SING_BOX_VERSION` → lx-версия (сверка «версия = пин» сохранить).
4. Проверка: `flutter build apk` проходит.
Acceptance B: aar + бинарь собраны, apk собирается, `dart test` текущий зелёный с lx-бинарем.

**Пакет C — разблокировка фич** (после синка: бинарь в `core/tool/bin/` + аудит OK):
1. `core/lib/src/parse/build.dart`: `case 'xhttp'` → `{'type': 'xhttp', mode/path/host/...}` по схеме

   `encryption` → `ob['encryption']` по SPEC lx, маркер снять.
2. Тесты: парсер-тесты (xhttp все режимы/параметры, vless encryption, негативные), конфиг-тесты

Acceptance C: новые тесты зелёные, check проходит xhttp/PQ-конфиги, `dart test` полностью зелёный
(golden — на мне).

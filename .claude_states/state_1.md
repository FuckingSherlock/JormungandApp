  от маршрута); здоровье серверов держит контроллер, DnsFailover переключает по его вердиктам (отдельный исполнитель, как
  Auto для нод); сбой сайта связывается с резолвером, через который он шёл (первая проверка — резолв хоста им же).

  для SNI. (б) DNS по умолчанию: DoH по IP Cloudflare → Google → AdGuard unfiltered → Local; Local — для прямого трафика.

  (г) Один объект DNS = провайдер с несколькими транспортами (DoH / DoT, по IP): в ядре — по серверу на транспорт,
  внутри объекта работает тот, что отвечает (тот же механизм здоровья/переключения); узел контроллера — транспорт, объект
  мёртв, когда мертвы все.
  Плюс (решено): пул проб толкает изменение сам (не по чтению `status`); токен отмены у проверок — смена контекста
  (нет сети / captive / свой перезапуск / ядро упало) обрывает их сразу; уровни сеть → ядро → маршрут → назначение:
  проверка через уровень с открытой первопричиной не запускается («пропущена» в протоколе).
  **Отмена не теряет подозрение:** если сбой начался ДО падения критического узла (сеть была), подозрение паркуется
  и после восстановления узла проверка возобновляется (не следствие и не сброс); если узел упал раньше сбоя — следствие.

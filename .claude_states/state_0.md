## Ждёт проверки на телефоне (из `8bf1d4a`)

- «Ignore site» в шторке: приложение не открывается, уведомление → «added to ignored sites · Undo» без звука, уходит через ~10 с; Undo снимает.
- Тап по одиночному уведомлению и по свёрнутой группе → своё событие (холодный / тёплый старт, с открытым листом).
- Raw при выключенных Connections: без флуда и лагов.
- Send report (висел на «Sending…»): проба `GET /v1/ping` напрямую 3 с → один путь (напрямую или через VPN, 10 с, без
  второй попытки); без прямого пути и VPN — `no-route`; общий срок 18 с, «Sending… N s», Cancel, переживает закрытие листа.
  Проверить: отчёт уходит, «Sent through the VPN…» при обходе, уведомление в Telegram (диагностика Worker: `_notify/last` в KV).
- Обновления: «Download & install» → сразу системный диалог, после отказа остаётся Install; свернуть во время загрузки →
  «Update X ready · Install», тап — приложение + один диалог; автоскачивание диалог не открывает; «New version» в
  Settings → Notifications отключает оба уведомления; канал `update` делят id 3 (ResumeNotifier) и id 4.
- Фоновая проверка обновлений (WorkManager, приложение смахнуто): `adb shell cmd jobscheduler run -f dev.jormungand.app <id>`,
  logcat `JormungandUpdateJob`, `<support>/update_job.log`; Install из уведомления при мёртвом процессе — системный диалог
  без окна приложения; Auto-check выкл — работа снята; после перезагрузки / обновления пакета работа на месте; Doze.
- Live connections → группировка App: имена и иконки приложений вместо id пакета.
- Settings → DNS: строки FakeIP больше нет (переработка — `to_think.md`).

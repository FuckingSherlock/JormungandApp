Когда пишется. Только если задет используемый сервер: маршрут, Manual-пин, цель правила или приложения, цепочка, профиль. Задеть могут: провайдер убрал сервер при обновлении; ты выключил или удалил сервер / подписку в Nodes.

Пара. «Недоступны» → «вернулись»: провайдер вернул, ты включил обратно. После удаления пары нет — вернуть нечего, текст без «goes back by itself».

Строки задетого — как строки проверки через разные ноды: что задето, куда сейчас идёт трафик. Тап по строке — настройка этого элемента.

Choose for all — окно выбора цели (то же, что «Send through» у правила); выбранная цель ставится всем задетым сразу.

Уведомление. Провайдер — да (тумблер «Subscription problems», по умолчанию вкл). Твои действия — без уведомления, только лента.

Под ним. Нынешние rules/targetLost / targetFound по этим серверам ложатся внутрь, как «+N связанных», без своих уведомлений.

Убираются. sub/removed, sub/back; изменения только свободных серверов — без события.

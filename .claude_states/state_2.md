## Решения пользователя 2026-10-14 (в силе)

- **Не прятать проблемы** (правило в `CLAUDE.md`): никаких «не чаще раза в N», молчаливых дедупов и глушения событий/
  логов; повторы — видимо (счётчик, время, строка в Raw), сокращение видимого — только с согласия пользователя.
- **Нумерация в чате**: один верхний уровень на ответ (1, 2…), подпункты N.1; номера пользователя сохранять.
- **Сайты**: проверка только по отвалу приложения; порядок: та же нода → разведчик (рабочая нода той же подписки, другой
  страны) + чекер параллельно (отменяется, если нода открыла) → ноды других подписок. Микросбой — только Raw. Чекер не
  открыл → «мёртв» без уведомления, отвалы 1,5 ч в счётчик, потом проверка одним чекером. Чекер открыл → игнор отвалов
  по лестнице 5/15/30/60 мин. Успешное соединение снимает запись; смена сети — только запись с лестницей.
  `site/blocked` и `site/unreachable` — разные события; «мёртв у всех» — без наших нод в событии.
- **Auto**: мёртвые ноды — лестница 1/2/4/8/15/20 мин (дальше 20), один лёгкий запрос, не сбрасывается (хранится в
  файле ядра), переподключение = одна внеочередная проверка, смена сети = сразу; общий заход для всего, что подходит в
  2 мин; текущая нода не пробуется при живом трафике. Проверяются только ноды основного потока и цели правил.
- **Подписки**: пустая / без нод / с ошибкой HTTP сторона загрузки — неудача стороны, без события, если данные получены;
  `sub/diverged` — только разные наборы нод (подробности свёрнуты). Интервал обновления — пользовательский (90 мин у
  `white` — его настройка, не баг); ноды у провайдеров реально умирают/оживают, случайных выдач нет.
- **Анимации**: приложение уже на Impeller (Vulkan); дальнейшее удешевление не критично (расход только при открытом окне).
  Лист DNS в beta.9: `1.raster` ~14 % (было 63–70 %).

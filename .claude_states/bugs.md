  ~13 мин); в sing-box уходит `urltest` из всех 853, до конца своего первого раунда он ведёт трафик через ПЕРВЫЙ член;
  первым был нестабильный узел (ответил только запасному чекеру → в пинг-книге «жив»); Auto выбрать сам не может (urltest
  не селектор), только `URLTest(group)`; 49 с трафика в мёртвый узел, переключение не попало в счётчик (`was == null`,
  `auto.dart:754`). Варианты: (1) выбор Fastest забирает ядро — селектор, первый узел по своим пробам, как Priority
  (рекомендовано, крупная переделка `config.dart` / `docs/core.md`); (2) urltest остаётся, перед connect ждать
  ограниченно лучших N и не ставить первыми неизмеренных; (3) узел, ответивший только запасному чекеру, не считать «живым
  с ms» для Fastest — нужно при любом варианте. Ещё: проверки Auto тормозили, потому что адреса чекеров резолвились через
  мёртвый прямой AdGuard (тот же DNS-баг: первая проверка DNS после подключения открыла корень только через 30 с, репорт
  `20261014-phmbw7`). **Auto целиком — обсудить с пользователем отдельно.**

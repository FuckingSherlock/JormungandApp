# Локализация (i18n)

Макет переведён на русский целиком; язык переключается в Settings → General → Language
без перезагрузки. Здесь — как это устроено и как это забирает Flutter-приложение.

## Механизм

- `design/src/js/03-i18n.js` — объект `I18N`; `design/src/js/04-i18n-ru.js` — словарь `I18N.ru`
  (в его шапке глоссарий). Язык лежит в `genCfg.lang` (`en` | `ru`), сохраняется вместе со
  снапшотом; `setGenCfg('lang', …)` вызывает `I18N.setLang`.
- **Ключ = английский текст как он отображается.** Английский — исходный язык, без словаря он
  показывается как есть.
- Плейсхолдеры: `{0}`, `{1}` — любой текст (переводится рекурсивно), `{#0}` — число.
  Значение-массив = формы множественного числа `[1, 2–4, 5+]` (правила русского: 11–14 — «много»);
  форму выбирает первый захват из одних цифр.
- Сложные фразы, которые собираются из кусков (падежи, согласование), не собираются в DOM
  из английских склеек: их оборачивают `t('… {0} …', v)` / `tn(n, '{0} nodes')`, а в словаре
  описывают целиком или по частям.
- DOM-слой: `MutationObserver` по `document.body` переводит текстовые узлы и атрибуты `title`,
  `placeholder`, `aria-label`, `alt` по совпадению всего текста (либо по частям, разделённым
  ` · ` и ` — `). Оригиналы хранятся в `WeakMap`, поэтому переключение обратно на en
  восстанавливает текст. JS, который заново пишет английский текст, переводится снова.
  Не трогаются: `script`, `style`, `textarea`, `[data-notr]`, строки Raw-лога (`.log-line`,
  `.log-time`, `.log-tag`).
- Вывод `t()` кладётся в DOM уже переведённым и до перерисовки не возвращается в английский.
- `I18N.locale()` — `ru-RU` / `en-GB` для дат, `I18N.en(node)` — английский текст узла
  (для кода, который читает текст обратно, например `chipValue`; нельзя сравнивать
  `textContent` с английской строкой).

## Что не переводится

Названия протоколов и терминов (TUN, sing-box, DNS, IP, CIDR, GeoIP, Geosite, SOCKS5, HTTP,
UDP, TCP, QUIC, FakeIP, UUID, URL, JSON, YAML, Regex), имена узлов, подписок, профилей,
цепочек, домены, ключи JSON, сырые строки sing-box и ядра, уровни `ERROR` / `WARN`. Текст,
который собирается не в DOM (экспорт логов, тело системных уведомлений через `evText`),
остаётся английским, пока не обёрнут в `t()`.

## Глоссарий

См. шапку `04-i18n-ru.js`. Главное: Nodes — «Узлы» (вкладка и везде), один узел — «узел» (падежи и род согласуются; «сервер» остаётся только для DNS-сервера и сервера подписки);
Profile — «профиль», Chain — «цепочка», entry/exit цепочки — «вход»/«выход». **Не переводятся** Auto, Fastest, Direct, Block, а также Default и Proxy как подписи/кнопки/значения (в пояснениях можно переводить) — английское слово стоит прямо в русской фразе («в режиме Auto», «идёт Direct»), и системный прокси — «sys proxy». Kill switch остаётся как есть.

## Проверки

`check.mjs` умеет `--lang ru` и пресеты `ru-home`, `ru-nodes`, `ru-route`, `ru-settings`,
`ru-rules`, `ru-rule-form`, `ru-logs` и др. (пресет без префикса, открытый в русском);
проверка «120 % на 320 px» идёт в обоих языках. `node design/tools/check.mjs audit-ru [пресеты|all]`
печатает латинский текст, оставшийся на странице в ru (имена и термины из списка выше
отфильтрованы). `node design/tools/i18n-extract.mjs [--missing]` перечисляет английские
строки из разметки и JS, которых ещё нет в словаре.

## Flutter

Словарь переносится в ARB (`app_en.arb` / `app_ru.arb`), ключи ARB — стабильные идентификаторы
вместо английского текста, `{0}` → именованные плейсхолдеры `{name}`, массивы форм →
ICU `plural` (`{n, plural, one{…} few{…} many{…} other{…}}`). `i18n-extract.mjs` даёт
полный список строк для первичного экспорта. Даты форматируются через `intl` с текущей локалью.
Порядок: язык из `genCfg.lang` → `Locale`; русские формы множественного числа Flutter
берёт из ICU, отдельного `plural()` не нужно.

Экспорт автоматический: `node app/tool/gen_i18n.mjs` (входит в `node app/tool/gen_all.mjs`) читает
`I18N.ru` и пишет `app/lib/l10n/app_en.arb` + `app_ru.arb`; `app/l10n.yaml` настраивает `flutter gen-l10n`.
- Ключ ARB — camelCase из первых слов английского текста (`"Text size"` → `textSize`; множественные —
  с суффиксом `Plural`; занятое имя → `…2`). Соответствие «английский текст → ключ» хранится в
  `app/tool/i18n_keys.json` и только растёт, поэтому повторный запуск не меняет ключи, уже
  использованные в Dart. Изменился английский текст — это новый ключ.
- `{0}` → `{s0}` (String), `{#0}` → `{n0}` (num), индекс сохраняется; массив форм → ICU `plural` по
  первому числовому плейсхолдеру (`one` / `few` / `many` / `other`). Английская форма `one` берётся из
  парного ключа словаря (`{#0} node` для `{#0} nodes`), этот парный ключ в ARB отдельно не попадает.
- Строки, которых нет в макете (только в приложении), — в `app/tool/i18n_extra.json`
  (`{"English": "Русский"}`); запись из макета приоритетнее.
- Переводятся только цельные строки; части «a · b» / «a — b», которые DOM-слой макета переводит по
  отдельности, во Flutter собираются из отдельных ключей. Всё, что должно остаться английским
  (список «Что не переводится»), в словаре и так отсутствует.
- Новая строка в макете → запись в `04-i18n-ru.js` (как раньше) → `node app/tool/gen_i18n.mjs`.

### Русский — только для stable

Правило: русские переводы делаются перед **стабильным** релизом, а не с каждой правкой текста
(иначе каждая правка английского требует переперевода). Новая строка приложения добавляется в
`i18n_extra.json` со значением `null`: `{"English text": null}`.
- `gen_i18n.mjs` кладёт такую строку только в `app_en.arb` (в `app_ru.arb` её нет); в русском
  интерфейсе она показывается по-английски — `flutter gen-l10n` без ключа в `app_ru.arb` собирается
  и подставляет английский текст шаблона. `null` годится для обычных строк и строк с `{0}` / `{#0}`;
  форма множественного числа (массив) требует русских форм сразу.
- `app/l10n.yaml`: `untranslated-messages-file: lib/l10n/untranslated.json` — gen-l10n пишет туда
  список ключей без русского (иначе печатает предупреждение). Файл производный и в `.gitignore`
  (`app/.gitignore`): источник правды — `i18n_extra.json`, список по английским текстам даёт команда ниже.
- `node app/tool/gen_i18n.mjs --missing` печатает строки без русского и завершается с кодом 1, если
  они есть; ничего не пишет.
- Перед stable-тегом: `--missing` → заменить `null` на русский текст (глоссарий выше) →
  `node app/tool/gen_i18n.mjs` → тесты; тег ставится, когда `--missing` чист. В тот же проход —
  заметки к stable `release-notes/X.Y.Z.en.txt` и `X.Y.Z.ru.txt` (`docs/updates.md`, «Заметки к релизу»):
  без них CI stable не выпускает.
- Тесты не требуют русского для каждого ключа (проверки полного покрытия ru в `app/test` нет); полнота —
  только шаг `--missing` перед stable.
